# Implementation contract v1
Python 3.11+, standard library only, no model SDK. All code at repository root. No real network inference until orchestration acceptance. Public code MIT; generated synthetic benchmark texts CC0. Credentials environment only, never public files.

## budget.py
Expose class BudgetLedger(path: pathlib.Path, cap_usd: str). Durable append-only JSONL with fsync; process lock lifetime, reject concurrent writer (POSIX flock allowed). Decimal dollar strings, finite nonnegative validation. reserve(request_id: str, upper_usd: str) -> bool; settle(request_id: str, actual_usd: str | None) -> None; snapshot() -> dict with cap_usd, committed_usd, remaining_usd. Reserved/unknown attempts retain full reservation after restart, duplicate IDs never sent again (reserve duplicate raises). Known actual > hold must persist actual, stop further reservations and flag overrun; don't conceal. Incomplete journal tail fail closed. Full usage validity is runner responsibility. Expose cost_usd(prompt_tokens:int, cached_tokens:int, completion_tokens:int, input_per_million:str, cached_per_million:str, output_per_million:str) -> str; reject bools, negatives, cache>input, nonfinite prices. No claimed guarantee of provider bill. All failures conservatively retain hold unless verified usage. Files budget.py test_budget.py only.

## transport.py
Expose stream_chat(base_url:str, api_key:str, payload:dict, timeout_s:float=120, on_event=None) -> dict. HTTPS only except loopback HTTP for testing, no redirects, no retries, stdlib http.client, monotonic_ns for all offsets and UTC start. Single request; open a fresh connection per request, explicitly document no keepalive (consistent cross-provider, includes connect/TLS). Cooperative elapsed deadline rather than a hard wall-clock guarantee: network reads use remaining time and callbacks are checked immediately after returning. DNS, standard-library header parsing and blocking local persistence cannot be safely preempted. Record audit_callback_ms; synchronous persistence can delay later network reads, so observer overhead is disclosed, not subtracted as if it were separable. Read SSE incrementally without waiting for arbitrary full buffers; bounded event size and total bytes. on_event(event:dict) invoked synchronously per decoded SSE event (include elapsed_ns, raw data string). Return JSON-serializable public record with started_at_utc, headers_ms, first_generated_ms, first_content_ms, last_generated_ms, total_ms, status, headers (strict allowlist request ids/rate limits/content-type/date only), events, final_usage (last usage only), response_model, finish_reason, done, error. Never return request authorization, api_key, secret errors, cookies. Reasoning_content and content first nonempty measured separately; role/empty events ignored. HTTP errors sanitized bounded body optional; error string generic exception type not arbitrary exception message. Distinguish EOF without DONE, invalid event JSON, invalid UTF8, timeout. on_event journal persistence runner responsibility. Explicitly disclose client receive-time not server token-time. Files transport.py test_transport.py only.
